# Cocoon: AI-Based Intelligent Food Packaging System
**Smart India Hackathon 2026 (PS ID: SIH26236)**

### 🎥 [Click Here to Watch the Live App Demo Video](https://drive.google.com/file/d/1SbavjdHiI8Omr13fVb-pcrmaCt3EVN9j/view?usp=sharing)

## Core Technologies
* **Frontend:** React.js, Tailwind CSS, Recharts
* **Backend:** FastAPI, Python, SQLite/SQLAlchemy
* **AI Integration:** Google Gemini Vision & LLM APIs (Strict Pydantic JSON validation)

## Key Features
1. **AI Vision Crop Auto-Profiling:** Extracts moisture, pH, and respiration rates from images.
2. **Packaging Decision Engine:** Deterministically calculates OTR, WVTR, and exact material specs.
3. **Interactive Simulations:** Live Shelf-life thermal decay slider and MAP Gas ratio visualizer.
4. **B2B Export:** FSSAI compliance tracking with 1-click PDF executive reports.
